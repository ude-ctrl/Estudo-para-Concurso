Revisão por Codex (IA), 16/10/2026. Fonte histórica intacta. Este registro compara os literais extraídos do HTML com a consolidação inicial revisada; a promoção de `0.1.0` para `1.0.0` preserva o texto dessa candidata.

São 139 alterações de campos, não esse número de questões. O original completo permanece em `provenance.json`; os recursos novos não são apresentados como conteúdo histórico. Os 32 gabaritos e os textos de suas alternativas corretas foram preservados.
